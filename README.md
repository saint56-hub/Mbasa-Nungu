# Mbasa Nungu — Armed Response & Protection Portfolio

GitHub Pages-ready security portfolio inspired by the dashboard/portfolio approach of the supplied Lungani Mncwango example.

## Features
- Armed Response / Armed Escort / Armed Guard / Rapid Response positioning
- Interactive operations tabs
- Recruiter dashboard
- Direct email and phone buttons
- Downloadable tailored CV PDF
- Cape Town availability / location section
- Security gallery
- Responsive mobile design
- No frameworks required

## GitHub Pages
Upload the complete folder to a GitHub repository, then enable **Settings → Pages → Deploy from branch → main → /(root)**.

## Assets
- `assets/security-operations.jpg` — supplied image
- `assets/Mbasa-Nungu-Armed-Response-CV.pdf` — downloadable tailored CV
- `assets/Mbasa-Nungu-Security-CV-Source.pdf` — original supplied CV PDF

## Notes
Security specialization and availability are based on the user's supplied briefing. Role-specific credentials should only be added when verified.
